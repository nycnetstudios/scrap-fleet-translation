# STARGRAVE Community Translations

Official community localization repository for **STARGRAVE** by NYC Net Studios.

English is the reference language. You can help improve an existing translation or add a new language without editing the game source code.

## Quick start

1. Download [`translations/template.csv`](translations/template.csv).
2. Rename it to the target locale, such as `es.csv`, `fr.csv` or `de.csv`.
3. Fill only the `translation` column. Do not change `key`, `en` or placeholders such as `{count}` and `%d`.
4. Submit the file through the [translation request form](../../issues/new?template=translation.yml) or open a Pull Request.
5. Every contribution is automatically checked and manually reviewed before entering the game. You can run the same check locally with `node scripts/validate_translations.mjs`.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the complete guide. Use [`reference/glossary.csv`](reference/glossary.csv) for official names and recurring terms.

# Traduções comunitárias de STARGRAVE

Repositório oficial de localização comunitária de **STARGRAVE**, da NYC Net Studios.

O inglês é o idioma de referência. Você pode corrigir uma tradução existente ou adicionar um idioma sem editar o código do jogo.

## Início rápido

1. Baixe [`translations/template.csv`](translations/template.csv).
2. Renomeie para o locale desejado, como `es.csv`, `fr.csv` ou `de.csv`.
3. Preencha somente a coluna `translation`. Não altere `key`, `en` nem placeholders como `{count}` e `%d`.
4. Envie pelo [formulário de tradução](../../issues/new?template=translation.yml) ou abra um Pull Request.
5. Toda contribuição passa por validação automática e revisão manual antes de entrar no jogo. A mesma verificação pode ser executada localmente com `node scripts/validate_translations.mjs`.

Consulte [CONTRIBUTING.md](CONTRIBUTING.md) para o guia completo e [`reference/glossary.csv`](reference/glossary.csv) para nomes oficiais e termos recorrentes.
